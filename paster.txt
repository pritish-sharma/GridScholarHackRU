1. Project "GridScholar" (Education Track)
The Problem: Chronic absenteeism in underfunded public schools (like those in surrounding NJ areas) is often blamed on the student, but it's heavily linked to hyper-local infrastructure—transit delays, severe weather, and lack of safe walking routes.
The Solution: A predictive early-warning dashboard for school administrators.

The Data Science: You merge historical public transit data (NJ Transit APIs or GTFS data), historical weather data, and simulated student attendance records.

The Model: Build a machine learning classification model (like a Random Forest) that flags specific neighborhoods or bus routes that have a high probability of causing severe absenteeism on a given day (e.g., "Heavy rain + Route 18 traffic = 40% expected absence for Zone B").

The Actionable Fix: The dashboard automatically suggests interventions, like dispatching an emergency shuttle to a stranded neighborhood or shifting specific cohorts to excused remote learning for the day before the bell even rings.

Why it wins: It uses geospatial analysis (maps always look great in demos), tabular data, and solves a systemic educational inequity without just saying "we built an AI tutor."

from google import genai
from google.genai import types
from pydantic import BaseModel, Field

# Define rigid schema for the hackathon demo
class EmergencyIntervention(BaseModel):
    zone_id: str
    predicted_absentee_rate: float
    root_cause_summary: str
    reroute_action_plan: str
    bilingual_sms_english: str
    bilingual_sms_spanish: str
    nj_doe_funding_waiver_draft: str = Field(
        description="Formal administrative waiver citing severe transit/weather hardship to protect state ADA funding."
    )

client = genai.Client(api_key=os.environ.get("GEMINI_API_KEY"))

def generate_intervention(zone_id: str, risk_score: float, transit_alert: str, weather_summary: str):
    prompt = f"""
    You are the Emergency Operations Director for the New Brunswick Public School District.
    Our ML model has flagged a critical chronic absenteeism event for tomorrow morning:
    - Zone: {zone_id}
    - Predicted Absenteeism Spike: {risk_score * 100:.1f}%
    - Weather Forecast: {weather_summary}
    - Transit Disruption: {transit_alert}

    Synthesize this quantitative risk data into an actionable intervention protocol. 
    Draft targeted transportation changes, community SMS alerts, and a formal NJ DOE attendance waiver.
    """

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=prompt,
        config=types.GenerateContentConfig(
            response_mime_type="application/json",
            response_schema=EmergencyIntervention,
            temperature=0.2, # Low temperature for reliable municipal tone
        ),
    )
    return response.text
